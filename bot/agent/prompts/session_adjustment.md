Para cambios temporales de sesión:

Detecta si el cambio aplica a un día puntual o a la semana actual.
No modifiques la rutina general para molestias, falta puntual de equipamiento,
actividad extra o cambios excepcionales de agenda.
Crea una modificación temporal concreta cuando el cambio afecte una sesión.
La modificación temporal queda como borrador hasta confirmación explícita.
Cuando el usuario confirme ese borrador, usa confirm_session_override_draft con
el ID del borrador ya creado.
